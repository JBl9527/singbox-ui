局域网透明网关必需

当前容器无权限创建或读写 /dev/net/tun 设备。目前 Sing-Box 正以 0.0.0.0:2080 端口代理 模式运行。若需使用局域网设备免客户端透明网关与 MetaCubeX 活跃流量抓取，请在 Proxmox VE (PVE) 宿主机 Shell 中执行以下 3 步开启直通：

# 1. 打开容器配置文件 (将 <CTID> 替换为当前容器编号，例如 100):
nano /etc/pve/lxc/<CTID>.conf
# 2. 在文件末尾添加以下两行:
lxc.cgroup2.devices.allow: c 10:200 rwm
lxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file
# 3. 重启容器生效:
pct reboot <CTID>
